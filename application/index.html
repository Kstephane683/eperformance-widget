Bon à savoir

Utiliser, installer, entretenir

Sans installation

Chaque application s’ouvre dans votre navigateur, sur téléphone comme sur ordinateur. Aucun compte, aucun téléchargement obligatoire.

Installer si vous voulez

L’installation se fait depuis le navigateur : l’application s’ajoute à votre écran d’accueil et s’ouvre en plein écran. Vous la retirez quand vous voulez.

Hors ligne

L’application s’ouvre même sans réseau et affiche un écran d’attente clair. La conversation reprend d’elle-même dès que la connexion revient.

Mia affiche une version ancienne après une mise à jour ? Videz le cache local de l’application, puis rechargez la page.
